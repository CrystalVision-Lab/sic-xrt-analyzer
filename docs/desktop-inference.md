# 데스크톱 고정 연구 모델 연결

프로그램의 기존 분석 실행 버튼에 `frozen_xrt_patch_classifier` v1을 연결합니다.
모델은 로컬 파일에서 불러오며 외부 서버, Jupyter, 재학습 없이 CPU로 실행합니다.
별도 네트워크 서버나 EXE 패키징은 이 변경의 범위가 아닙니다.

## 설치와 사용

```powershell
cd C:\Users\PC-1\capstone\sic-xrt-analyzer
.\.venv\Scripts\python.exe -m pip install -e ".[viewer,imagej,research]"
.\.venv\Scripts\python.exe -m sic_xrt_analyzer
```

1. 오른쪽 **분석 → 연구 모델 폴더 선택**에서 manifest.json/model.onnx 폴더를 선택합니다.
   성공한 경로는 사용자 설정에 저장되어 다음 시작 시 자동 연결됩니다.
2. RGB 8비트 TIFF 또는 JPG/JPEG 영상을 엽니다. JPG는 원해상도로 디코딩한 RGB 값을 분석하며, 화면의 축소 영상이나 밝기 조절 결과를 입력하지 않습니다.
3. **전체 이미지** 또는 선택한 **ROI**를 분석 범위로 지정합니다.
4. **밝기 대비 후보 찾기** 또는 **제공 좌표 CSV 분류**를 선택합니다.
   CSV 열은 point_id(선택), x, y이며 원본의 0 기반 픽셀 좌표입니다. 영상/페이지가 바뀌면 CSV 연결이 해제됩니다.
5. 오른쪽 위 **분석 실행**을 누릅니다. **결과** 탭에 후보 수·점수·좌표가 나타나고 영상에 원으로 표시됩니다.
6. **CSV·JSON 결과 저장**으로 선택한 폴더 아래 실행별 새 결과 폴더를 만듭니다.

## 시작 시 모델 검색

환경변수 `SIC_XRT_MODEL_BUNDLE`, 사용자 설정의 마지막 성공 폴더, 앱 폴더의 `models/research` 및 `artifacts/models/research` 순서입니다. 개발 설치에서는 pyproject.toml이 있는 설치 저장소를 먼저 찾고 현재 작업 폴더도 확인합니다. 따라서 저장된 사용자 설정이 없어도 배치한 모델을 찾으며, 다른 폴더에서 실행해도 설치 저장소를 기준으로 연결합니다. 명시한 환경변수나 저장된 경로가 잘못된 경우 다른 모델로 조용히 바꾸지 않고 오류를 표시합니다.
EXE 배포 시 실행 폴더는 실행 파일 기준입니다. 모델은 Git에 넣지 않습니다.
최초 연결 시 버전·입출력 규약·SHA-256을 확인하며 로딩 실패 상태에서 분석은 실행되지 않습니다.
모델 로딩과 추론은 기존 Qt 작업 스레드에서 수행합니다. 창 종료는 진행 작업의 취소와 정리를 기다립니다.

## 좌표·메모리·취소

JPG도 기존 원본 픽셀 계약의 메타데이터·파일 정체성·영역 읽기를 통해 분석에 전달합니다.
저장된 좌표는 EXIF 회전을 적용하지 않은 원본 픽셀 좌표이며 TIFF로 변환하거나 JPG를 재저장하지 않습니다.
큰 JPG는 뷰어가 준비한 원해상도 RGB 임시 디스크 캐시에서 패치를 읽습니다. 화면의 축소본·밝기 조절은 입력에 영향을 주지 않습니다.
파일 교체 시 기존 결과와 CSV 연결을 폐기합니다. 모델 산출물 계약 v1, 모델 해시와 출력 스키마는 그대로입니다.

소스 기반 어댑터의 `analyze_source(request, token)`을 기존 분석 파이프라인의 선택적 확장으로 추가했습니다.
기존 배열 기반 어댑터도 계속 지원합니다. 원본 정체성 확인, 요청별 ID, 파일 교체 후 늦은 결과 폐기는 유지합니다.
큰 TIFF를 통째로 복사하지 않고 후보 탐색은 1,024픽셀 타일과 64픽셀 여유 영역, 분류는 128픽셀 패치 32개 단위로 읽습니다.
타일/추론 배치 사이에서 취소를 확인합니다. ROI 분석은 경계 밖 픽셀을 사용하지 않으며 완전한 패치를 만들 수 없는 점은 제외합니다.
기존 원본 리더의 압축 TIFF 디코딩 크기 제한은 그대로 유지합니다. 지원되지 않는 대형 압축 영상은 오류로 중단합니다.

자동 후보는 강도 순으로 최대 3,000개를 선택합니다. 작은/긴/희미한 결함 누락이나 중복 후보가 있을 수 있으며,
상한 도달을 결과에 표시합니다. CSV는 최대 50,000행/10 MB입니다. 후보 목록은 100개씩 페이지를 넘겨 전체 결과를 탐색하며 내보내기는 필터와 관계없이 전체 결과입니다.
레이어는 원본 좌표를 확대·이동 배율에 맞춰 그립니다. 이 표시를 ImageJ 정답 ROI로 자동 변환하지 않습니다.

## 검증과 해석

실제 웨이퍼 1의 제공 좌표로 데스크톱 UI에서 1,929개를 분류했습니다(BPD 109, TED 520, TSD 1,300).
이전 Jupyter 결과와 좌표별 예측 종류가 모두 일치했고, 원본 SHA-256은 유지되었습니다.
Windows GUI 실측에서는 약 4~7초였으며 장비·캐시·입력 조건에 따라 달라집니다. 정확도 평가 수치가 아닙니다.
자동 대비 후보와 CSV 분류, ROI 원본 좌표, 취소, 잘못된 모델, 파일 교체 시 좌표 해제, CSV/JSON 저장,
QML 버튼·결과·레이어의 통합 테스트를 추가했습니다.

현재 출력은 연구용 3종 분류 후보입니다. BPD 오탐, 미검출, 원본 좌표 오차가 남아 있습니다.
전문가 검수, 세부형 a–f, 3D 분류·재구성, 물리적 전환 판정은 이 기능이 수행하지 않습니다.
전후 정렬·추적은 기존 연구 노트북 기능으로 유지되며, 이 PR은 데스크톱 분류 연결을 완성합니다.

JPG 연결 수정 검증: 실제 `After annealing_1.jpg`(12,349×12,273)를 Windows 분석 버튼으로 실행해
약 7.8초에 후보 2,946개를 분류하고 CSV/JSON으로 저장했습니다. 후보 상한 3,000개 중 경계 54개는 제외했습니다.
원본 해시는 동일하고 QML 경고는 없었습니다. 분석 중 반복 JPEG 디코딩/전체 배열 읽기 없이 준비된 캐시를 사용했습니다.
이 수치는 속도·연결 검증이며 결함 분류 정확도 평가가 아닙니다.

## 후보별 탐색

분석 후 **결과** 탭에서 전체/BPD/TED/TSD 필터, 낮은 점수 필터, 번호·후보 ID 검색을 사용합니다.
필터는 목록과 이미지 위 후보 표시를 함께 변경합니다. 100개씩 넘기는 페이지 버튼으로 모든 후보에 접근할 수 있습니다.
목록 또는 Pan 도구 상태에서 이미지의 원을 클릭하면 해당 후보를 선택합니다. 화면은 450ms 동안 부드럽게 확대·이동하여 후보를 중앙에 놓고 노란 십자와 번호로 강조합니다.
다음/이전은 현재 필터 안에서 이동하고 **전체 보기**로 영상 전체로 돌아갑니다. 직접 드래그·줌 조작은 진행 중인 이동 애니메이션을 중단합니다.

상세 카드에는 후보 번호·원래 point_id, 원본 X/Y 좌표, 원본 128px RGB 패치, 세 종류의 모델 점수가 표시됩니다.
패치는 비동기 원본 읽기를 사용하고 화면의 밝기 조절과 무관합니다. 이 점수는 보정된 정답 확률이 아닙니다.
**실행 정보**에서 원본 파일·페이지·좌표 기준·분석 방식·소요 시간·실행 ID·모델 해시를 확인하고 텍스트를 복사할 수 있습니다.
선택한 위치의 **복사** 버튼으로 후보 ID와 좌표를 복사합니다.

**살펴봄**은 이번 분석 결과 안에서 선택해 본 기록이며 정답 검수·라벨 수정·영구 검수 기록이 아닙니다.
영상·페이지·모델 또는 분석 결과가 바뀌면 오래된 선택·패치·살펴봄 기록을 초기화합니다. 다른 후보를 빠르게 선택하면 이전 패치 요청의 늦은 결과를 버립니다.
CSV 기존 열은 유지하며 JSON의 각 후보에는 화면 번호와 세 종류의 점수 배열(BPD, TED, TSD 순서)이 추가됩니다. 기존 예측·모델·원본·사람 검수는 변경하지 않습니다.
### 선택 후보 자동 ROI

결과 탭의 **자동 ROI**는 기본 켜짐입니다. 목록/표시점 선택 및 이전·다음 이동 시 후보를 중심으로 128×128 원본 픽셀의 탐색 사각형을 생성합니다. 256·512픽셀로 바꿀 수 있으며, 영상 가장자리에서는 영역을 안쪽으로 옮기고 영상보다 큰 크기는 영상 크기로 제한합니다. 확대 배율도 선택한 ROI 크기에 맞춥니다. 이 사각형은 결함 윤곽이나 정답 라벨이 아닙니다.

자동 ROI를 끄면 마지막 영역이 유지됩니다. 수동 ROI 드래그, 가져온 ROI 외접 사각형 선택, ROI 초기화는 자동 추적을 해제합니다. 필터로 선택 후보가 사라지거나 결과가 무효화되면 자동으로 생성된 ROI만 정리합니다. 직접 분석 실행을 누르면 현재 ROI를 고정해 새 분석에 전달하므로 이전 결과가 지워져도 분석 영역은 유지됩니다.

좌표 복사와 분석 탭의 ROI 범위 선택에 기존 사각 ROI를 그대로 사용합니다. 자동 재분석이나 모든 후보의 ImageJ ROI ZIP 저장은 수행하지 않습니다. 모델·분류 라벨·외부 계약은 변경하지 않습니다.
