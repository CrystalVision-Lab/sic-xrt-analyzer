# 분석 결과를 수정하며 자료를 쌓기

이미지를 열고 분석한 뒤 **결과 → 후보 선택 → 선택 후보 검수하기**를 누른다.
검수자명은 기본값 양희승이며, 실제 확인하는 사람의 이름으로 바꿀 수 있다.
웨이퍼 번호를 지정하고 설정을 누른다. 이름을 입력하거나 후보를 조회하는 것만으로 검수 완료가 되지는 않는다.

| 동작 | 저장되는 정보 |
|---|---|
| O · 결함 있음 | 결함 유무만 확인. 예측 종류·좌표를 정답으로 확정하지 않음 |
| X · 결함 아님 | 선택 지점이 배경/얼룩임을 확인 |
| 종류 저장 | BPD/TED/TSD 또는 종류 미확정. 종류가 틀리면 이 동작으로 수정 |
| 이 위치 맞음 | 현재 지점을 중심 좌표로 확인 |
| 위치 수정 | 원본 영상에서 같은 결함의 올바른 중심 클릭 |
| 누락 추가 | 모델이 놓친 결함의 중심 클릭. 종류는 별도로 확인 |
| 중복 | 같은 영상에서 대표 후보를 지정. 중복 항목은 학습에서 제외 |
| 보류 | 판단이 불확실한 항목. 학습에서 제외 |
| 되돌리기 | 직전 동작 이전 상태로 복구하며 변경 이력은 유지 |

종류가 틀린 결함에 X를 누르면 배경으로 잘못 학습할 수 있다. 위치가 어긋나면 위치 수정으로 중심을 옮긴다.
검수 결과는 녹색, 배경은 빨간 X, 보류·중복은 회색으로 표시한다. 선택한 좌표는 노란 십자가이며 원래 좌표와 이동 선도 남긴다.
목록에서 선택하면 해당 위치로 부드럽게 확대된다. 좌표 선택은 Esc로 취소한다.

기록은 사용자 앱 데이터의 reviews 폴더에 원본 SHA-256/페이지별로 자동 저장한다. 파일을 다시 열면 복원한다.
**검수 자료 내보내기**로 선택한 폴더의 새 feedback_* 폴더에 feedback.json을 만든다.
불러오기는 같은 원본·페이지만 허용하며, 충돌하는 수정 이력은 덮어쓰지 않는다. 두 프로그램 창의 동시 저장도 검사한다.
내보내기는 현재 필터와 무관하게 세션 전체 이력을 포함한다.

## 학습으로 연결되는 계약

Analyzer 출력은 `xrt_feedback_v1`. Data Tools가 검증·패치 추출해 `xrt_feedback_dataset_v1`로 변환하고 ML이 읽는다.
좌표는 EXIF 회전·반전 없이 파일에 저장된 원본 픽셀의 x/y, 페이지는 0부터 시작한다.
원본 파일 해시, 페이지, 영상 크기, 예측 당시 분석 ID·모델 해시, 검수자·시간·사유, 수정 전후 상태가 보존된다.
과거 이벤트와 원래 예측은 변경하지 않는다. 원본 파일도 수정하지 않는다.

결함 유무·종류·위치 확인은 각각 별도 학습 마스크다. 모델 예측은 종류 정답으로 자동 승격되지 않는다.
표시되지 않은 영역은 배경 정답이 아니다. 누락 추가가 없는 검수 결과로 전체 영상 재현율을 주장할 수 없다.
종류 전문 지식이 없으면 종류 미확정을 사용한다. 사람의 확인도 전문가 정답과 동일하다고 주장하지 않는다.
`expert_ground_truth=false`, `exhaustive_annotations=false`를 유지한다.

현재 변환은 원본 8비트 RGB TIFF/JPG의 128px 패치만 지원한다. 잘린 가장자리 패치와 32px를 넘는 위치 보정은 이유를 기록하고 제외한다.
BPD의 선·윤곽, TED a~f·TSD 세부 종류, 어닐링 전후 대응과 3D 층/물리 길이는 이 점 검수만으로 확정되지 않는다.
웨이퍼 8은 최종 시험용이므로 학습 변환·개발 학습에서 거부한다.

검수 클릭은 학습·모델 교체를 실행하지 않는다. 검수 자료가 쌓이면 고정된 웨이퍼 분리와 기존 자료 보존 하에 일괄 학습한다.
새 모델의 결함 유무·종류·위치 오차를 각각 평가하고 전체 영상 누락도 별도로 평가한 뒤 적용 여부를 판단한다.
현재 연구 모델과 ONNX 연결은 이 기능으로 교체되지 않는다.
