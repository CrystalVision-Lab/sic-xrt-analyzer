# 연구 작업 가이드

## 설치 · 기기 등록

처음 실행할 때 연결 상태를 확인합니다.

### 시작하기

설치 후 처음 시작하기 화면에서 기기 ID를 복사해 관리자에게 전달합니다. 관리자가 발급한 서버 주소와 기기 인증키를 입력하고 저장하고 연결 확인을 누르세요.

### 로컬 기능으로 시작

등록을 기다리는 동안 이미지 보기, ImageJ 처리, 로컬 3D를 사용할 수 있습니다. 파일 → 기기 등록 · 서버 연결에서 나중에 등록할 수 있습니다. 관리자 웹 로그인 비밀번호는 기기 인증키가 아닙니다.

### 서버 기능

서버 동기화, 신고 전송, 승인 모델 받기는 등록된 기기 인증이 필요합니다. 프로젝트를 저장한 뒤 필요한 자료만 명시적으로 전송하세요. 원본은 자동 업로드되지 않습니다.

## 원본 · 결과 검토

원본을 보면서 주변 후보를 차례로 확인합니다.

### 이미지 열기

파일 → 열기에서 JPG/TIFF를 엽니다. 화면 맞춤은 전체 분포, 100%는 원본 픽셀 확인에 사용합니다. 표시 밝기·배율은 분석 입력을 바꾸지 않습니다.

### 전체 분포

분석 후 금색 BPD 윤곽, 파란 TED 점, 분홍 TSD 점이 원본 위에 표시됩니다. 결과 → 설정에서 후보 표시 강도와 분포 색 농도를 조절하세요. 색 농도를 0으로 두면 원본과 후보만 보입니다.

### 영역 검토

영상의 영역을 누르거나 첫 영역 확대를 누릅니다. 주변 후보 썸네일 → 원본 확대 → 확인/보류 순서로 검토합니다. 후보 비교에서 여러 위치를 나란히 살펴보고 검출 숨김으로 원본만 비교할 수 있습니다.

### 누락 · 제한 확인

후보 한도와 제외 개수를 확인하세요. ROI 경계 밖의 실제 원본 픽셀은 패치 문맥으로 사용하지만 사진 자체의 테두리 64px 안은 완전한 128×128 입력이 없어 제외될 수 있습니다. 후보 수는 실제 결함 총수가 아닙니다. 누락 위치에 ROI를 그려 신고 대기에 기록하세요.

## 동일 결함 · 3D

확대 원본, 연결 과정, 직교 단면을 함께 확인합니다.

### 결함 선택

여러 페이지 흑백 TIFF에서 검은 결함 안쪽을 선택합니다. 왼쪽은 결함 확대, 작은 화면은 전체 위치입니다. 전체 사진으로 전환하거나 가운데 경계를 끌어 두 패널 크기를 조절하세요.

### 재생 · 재지정

0.5× / 1× / 2×로 관찰 속도를 바꿉니다. 일시정지와 다음 단계로 단면을 확인하세요. 모호한 교차에서는 같은 결함 지정 또는 다른 결함 제외로 원본의 위치를 직접 선택합니다. 빠르게 완료는 애니메이션 대기를 생략합니다.

### 표면 · 단면 비교

완료 후 원본 직교 단면 비교를 누르면 uint16 TIFF의 XY / X–Page / Y–Page를 볼 수 있습니다. 단면 클릭으로 위치를 맞추고 휠로 페이지를 이동합니다. 3D 표면으로 돌아와 분할 결과를 대조하세요. ImageJ Orthogonal Views와 같은 축 구성의 앱 내 보기이며 Java 3D 플러그인 자체는 아닙니다.

### 연결의 의미

6픽셀 이내 이동은 형태 겹침이 충분하고 경쟁 후보가 없을 때만 연결합니다. 빈 페이지나 모호한 분기는 자동으로 채우지 않습니다. 페이지 순서와 표시 간격은 물리적 Z 깊이 또는 동일 결함의 확정 증거가 아닙니다.

## ImageJ 처리

현재 페이지 복사본을 처리하고 원본을 보존합니다.

### 기본 처리

ImageJ 설정에서 Gaussian, Median, Mean, Minimum, Maximum, Variance, Unsharp Mask, Remove Outliers, Subtract Background를 한국어 입력으로 실행합니다. 처리 범위와 ROI를 먼저 확인하세요.

### 처리 결과

결과는 작업 복사본입니다. 저장할 때 새 파일을 선택하세요. 전체 스택 필터, ROI Manager 양방향 동기화, 모든 외부 Fiji 플러그인의 내장 지원은 아직 완료되지 않았습니다.

## Wafer Map

이미지 배치와 관측 후보를 확인합니다.

### 배치

프로젝트에 JPG와 분석 결과를 등록한 뒤 Wafer Map에서 배치합니다. 임시 배치는 물리 좌표 보정이 아닙니다. 실제 스케일과 대응점이 확인된 경우에만 물리 배치를 사용하세요.

### 탐색

BPD/TED/TSD 레이어를 선택하고 확대·이동합니다. 축소 화면에서는 같은 3px 셀의 표시 점을 묶지만 요약 개수는 원래 후보를 기준으로 유지합니다. 후보를 선택하면 해당 원본 위치에서 검토할 수 있습니다.
