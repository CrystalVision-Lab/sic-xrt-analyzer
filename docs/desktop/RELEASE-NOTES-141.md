# 릴리스 정보 배치 (#141)

## 사용자 화면

- 상단 메뉴: 다운로드 / 사용 가이드.
- 하단: 개발 노트 링크 및 해당 다운로드와 같은 버전의 GPLv3 대응 소스 링크.
- 개발 노트: 최근 3개 공개 버전, 버전별 주요 변경 최대 3개. 파일 해시·빌드 정보·배포 관리 버튼은 관리자 화면에서 확인한다.
- `/notes`를 직접 열 수 있으며 기존 `/releases` 주소는 `/notes`로 연결된다. 가이드는 기존처럼 로그인 없이 제공한다.
- 프로그램 0.4.3 업데이트 모달: 주요 변경 사항을 최대 3개 목록으로 표시한다. 새 버전 등록자는 사용자에게 영향을 주는 변경 2~3개를 줄바꿈으로 작성한다. 기존 문장형 notes도 지원하며 없는 변경을 생성하지 않는다.

## 관리자 화면

모든 등록 버전을 기존 관리자 인증 뒤에 유지한다. 버전별 배포·검증 이력에서 설치·소스 SHA, 소스 리비전, 배포 승인, 서명 상태, 전체 notes, 모든 상태 변경의 실행자·일시·근거를 확인한다. 원본 JSON도 유지한다.

서버 게시 조건은 설치 파일·대응 소스의 SHA 대조다. 기능 테스트 결과는 운영자가 남긴 배포 근거이며 자동으로 새 PASS나 모델 정확도 개선을 추정하지 않는다. 이번 작업은 릴리스 스키마/API/DB/분석 데이터 계약을 바꾸지 않는다.

## 배포

기존 현재 PC Docker 웹 서비스와 고정 Funnel 주소를 사용한다. 웹 교체는 web 서비스만 대상으로 하며 연구 API·DB·릴리스/모델 볼륨은 유지한다. 프로그램 패키지는 0.4.3으로 별도 빌드하고 같은 리비전의 GPLv3 대응 소스와 함께 게시한다.

UI 라이브러리 검토는 [검토 문서](../ux/UI-LIBRARY-REVIEW-141.md)를 따른다.
