# 0.6.4 연구 작업 흐름 개편

- 첫 실행에서 기기 등록 또는 로컬 사용을 선택하고 앱 안의 오프라인 사용 가이드를 열 수 있습니다.
- 결과 분포 위에서도 후보를 확인하고 표시 강도와 분포 농도를 조절할 수 있습니다.
- 3D 추적은 결함 확대 화면을 기본으로 제공하며 0.5/1/2배속, 패널 크기 조절, 선택 위치의 원본 직교 단면 비교를 지원합니다.
- ROI 경계의 후보는 실제 원본 문맥으로 분석합니다. 사진 자체의 경계에서 입력 패치가 부족한 경우는 제외 이유를 표시합니다.
- Wafer Map의 후보 좌표를 일괄 변환해 이동 시 처리량을 줄였습니다.

ImageJ 0.6.3의 내장 처리와 서버 사용자명 로그인은 유지합니다. 모델은 변경하지 않았으며 BPD 인식률이나 실제 영상의 동일 결함 추적 정확도 향상을 보장하지 않습니다. 실제 영상 검증과 입력 계약은 WORKFLOW-VALIDATION-166.md에 기록했습니다.

설치판과 대응 소스는 동일한 커밋으로 생성합니다. 게시 전 최종 CI, 설치 실행, 공개 다운로드의 크기와 SHA256을 확인합니다. 비공개 원본·모델·인증키는 배포에 포함하지 않습니다.
