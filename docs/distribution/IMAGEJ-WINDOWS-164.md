# Windows 0.6.3 ImageJ 내장 처리 배포

#160에서 병합한 ImageJ 기본 처리 9종을 Windows 설치판에 포함한다. 가우시안·중앙값·평균·최솟값·최댓값·분산 필터, 선명하게, 이상 픽셀 제거, 배경 제거를 앱의 한글 설정 화면에서 실행한다. 실제 ImageJ 1.54p 엔진을 사용하며 현재 페이지 복사본을 처리하고 원본을 유지한다. 고급 옵션 입력도 유지한다.

0.6.2 경량화 정책과 BETA 채널을 유지한다. xrt_app_release/v1 계약, 서버/API/프로젝트 스키마 변경 없음. 설치 EXE와 동일 커밋의 GPLv3 대응 소스를 함께 제공하며 모델·원본 데이터·비밀값은 포함하지 않는다. 코드 서명 상태는 UNSIGNED다.

Frozen smoke는 기본 UI/3D/코덱/작업자 검사에 추가하여 내장 처리 화면 9종의 로드와 실제 ImageJ 연산 결과를 직접 엔진 호출과 비교하고 원본 보존을 확인한다. 번들 및 별도 QA 설치에서 이 검사를 수행한 뒤 게시한다.

Windows 패키지의 최초 실행 검사에서 Java 탐색이 10초를 초과했다. 부하가 있는 PC에서도 초기화를 기다릴 수 있도록 제한을 30초로 늘린다. 비교 검사는 명령마다 독립 입력 복사본을 사용하여 이전 연산의 작업 상태가 다음 기준 결과에 섞이지 않게 한다.

이 배포는 ROI Manager 양방향 동기화, 임의 Fiji 플러그인 UI의 내장화, 전체 가상 스택 처리의 완료를 의미하지 않는다. 전체 스택 결과 보존은 #159에서 별도로 추적한다.
