Use case: precise-object-edit. Simplify this app emblem into a clean FLAT two-color icon while preserving its overall circular orange arc, blue wafer and three blue XRT slices. Remove all shadows, gradients, highlights and stray speckles outside the mark. Use solid deep blue #064591 and orange #ef7400. Wafer grid should have only 3 large cells across, slices should have only 2 simple white/transparent holes each. Keep all edges smooth and clean. Compact balanced square emblem, modest 10% padding, transparent background, symbol only, no text. Must look crisp and recognizable at 32 pixels.
