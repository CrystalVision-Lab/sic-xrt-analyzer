# 이미지 작업 흐름 정리 — Issue #129

## 화면과 상태

- 분석은 현재 단일 페이지 원본에서 확인 모달로 시작한다. 좌표 CSV와 모델 폴더 변경은 일반 분석 화면에서 제공하지 않는다. 설치한 Registry 모델을 기존 로컬 설정보다 우선한다. 입력 채널·dtype 계약은 그대로다.
- 완료 결과는 원본 Identity와 모델 ID/버전으로 묶어 최근 8개 이미지에서 메모리에 유지한다. 패널 닫기·작업 화면 왕복·같은 파일 다시 열기는 재추론하지 않는다. 디스크 보존은 기존 프로젝트 저장을 이용한다.
- 결과는 현재 원본과 일치할 때만 표시한다. 저장 이력에 원본이 없거나 SHA가 준비되지 않으면 확인/재연결 모달을 연다. SHA 검증을 생략하지 않는다.
- 처리한 원본 타일과 실제 완료된 후보를 worker progress로 표시한다. 취소·파일 전환·오래된 generation의 후보는 폐기한다.
- 결과는 분류 필터, 후보 목록, 영상 이동, 상세, 선택 신고로 구성한다. 분류 필터는 해당 영상 레이어도 선택한다. 점수는 모델 점수이며 검출 정확도로 해석하지 않는다.

## 간단한 작업 공간

Wafer Map은 폴더의 단일 페이지 JPG/TIFF를 최대 500개 읽어 원형 접촉 시트로 표시한다. `임시 배치`는 촬영 위치를 뜻하지 않는다. 왼쪽 드래그로 이동하고 더블클릭하면 원본을 연다. 축소는 0.05배에서 멈추며 화면 맞춤은 별도 동작이다. 원본은 읽기 전용이다.

정합은 저장 프로젝트에서 전/후 JPG를 선택하고 분석한다. 원본 crop 기반 좌우·겹침·차이 표시와 결과 모달을 제공한다. 기존 정합 자산·변환·검증 계약을 보존한다. 대응 근거가 부족하면 실패 결과를 보인다.

3D는 일반 탐색 메뉴에서 제거했다. 여러 페이지 TIFF에서 ROI를 지정한 뒤 3D 보기를 연다. 최대 64 MiB 원본 ROI 예산에 맞춘 표시 샘플 간격을 선택하며 원본 XY/Page 좌표를 유지한다. 페이지 축은 물리 Z 재구성이나 3D 결함의 확정 모델이 아니다. 기존 수동 추적 및 저장 API는 유지된다.

## ROI와 신고

ROI 레이어는 원본 좌표의 사각형 또는 선택 ImageJ ROI 도형을 복사해 각각 표시/숨김/삭제한다. 최근 8개 이미지에 대한 세션 레이어이며 원본과 추론 입력을 수정하지 않는다. ImageJ ROI ZIP 저장은 기존 기록 도구를 사용한다.

신고는 선택 사항이다. 후보, 원본 Identity/SHA, 모델 버전, 선택 ROI의 사각형/Polygon/Line 도형과 메모를 별도 로컬 JSON에 저장한다. 기본 위치는 AppLocalDataLocation/reports이며 `SIC_XRT_REPORT_DIR`로 지정할 수 있다. 자동 서버 전송이나 정답 승인/재학습은 하지 않는다. 기존 검수·중앙 동기화 데이터 계약은 변경하지 않는다.

## BPD 영역 제안

ONNX는 기존 128px RGB 점 분류 모델이다. 별도 국소 대비·연결 성분 영역을 원본 128×128 문맥에서 제안하고 `EXPERIMENTAL_LOCAL_CONTRAST_REGION`으로 구분한다. 도형은 모델의 POINT Geometry, 점수, BPD/TED/TSD 분류를 교체하지 않는다. 문맥 경계에 걸리면 region_clipped를 기록한다. 영역 제안 오류는 해당 제안만 비우고 분류 결과를 유지한다. 넓은 선·분기 구조의 전체 범위나 실제 분할 정확도는 검증하지 않았다.

구조 실험 엔진을 모든 후보에 직접 연결했을 때 실제 노이즈에서 `Degenerate junction loop`가 발생했다. 이 경로는 최종 기본 분석에서 제거했다. 기존 구조 실험 번들의 그래프/Mask 기능은 레이어 창에 유지한다.

## 검증 기록

- 기존 UI 테스트 함수 및 파라미터 사례를 유지하고 제거된 사이드바/고급 UI의 기대값을 새 모달·레이어·선택 신고로 개별 갱신했다. 원본, dtype, 좌표, 점수, Export byte 대조와 오래된 worker 거부 검사는 유지한다.
- UI 묶음: 105 PASS. 같은 실행의 기존 지도 API 4건은 활성화 메서드 이름 오류로 setup 실패하여 activate(True)로 정정했다. 이후 지도/3D 묶음에서 해당 4건과 기존 3D 검사가 통과했다.
- 실제 After annealing_1.jpg (12349×12273 RGB8): 후보 2946, BPD 영역 제안 245, 실제 progress 이벤트 250. 단회 실행 40.77s와 글꼴 검증 재실행 37.61s는 회귀 작업과 동시에 수행했으며 성능 개선 수치로 사용하지 않는다.
- 영역 제안을 켠/끈 실행의 분류·모델 점수·원본 좌표가 모두 같았다. 패널 닫기/복원, 다른 작업 공간 왕복, 파일 닫기/재열기 캐시가 통과했다.
- 실제 N119 TIFF (3072×3012, uint16, 158페이지): 분석 버튼 없음, 원본 64×64 ROI의 페이지 Volume 및 XY 단면 통과. 이번 offscreen QA는 GPU 실사용 성능 검사와 구분한다.
- 실제 폴더: 355개 표시, 읽을 수 없는 JPG 1개를 별도 오류로 구분. 반복 축소 시 0.05배 유지.
- JPG/TIFF/ONNX SHA 전후 일치. QML 경고 0. 실제 자료·캡처·실패 로그는 artifacts에만 보관한다.
- 최종 통합 회귀: 771 PASS / 5 SKIP (Windows 비대상 GUI 검사). 캐시 재열기 및 버전 일치 수정 포함. 이후 ROI 도형 첨부·겹침 표시 보강에 대해 관련 46건 및 실제 QML Polygon 신고/레이어 검사 1건이 추가 PASS했다.
- CI e2301a3: quality, server-postgres, distribution-portal 모두 PASS.
- 첫 전체 검사에서 기존 사이드바 기대값 11건이 실패하여 모든 함수·좌표·저장 검증을 유지한 채 갱신했다. 재검사 50건, 기존 검수 컴포넌트 실제 입력/저장/충돌 4건 PASS.
- 설치·앱 내부·패키지 버전 일치 gate를 추가했다. 내부 상수가 남은 첫 빌드는 중단했고 게시하지 않았다.
- 설치 실행 파일 최종 검증 및 게시 결과는 릴리스 완료 뒤 추가한다.

## 배포

목표 버전 0.2.0. 기존 in-app update와 GPLv3 대응 소스 계약을 이용한다. 운영 원본, 연구 자료, 모델과 Credential은 설치 파일에 포함하지 않는다. 기존 Native Dialog 안정화 코드는 변경하지 않았다. 기존 stacked PR은 병합/rebase/retarget하지 않았다.
