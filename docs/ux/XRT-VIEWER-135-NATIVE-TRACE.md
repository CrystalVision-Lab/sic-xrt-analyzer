# XRT Viewer #135 — 원본 확대와 단일 결함 적층

## 변경

Wafer Map은 정합용 축소 영상과 원본 표시를 분리한다. 정합 결과와 원본 좌표는 유지하고, 확대 시 현재 뷰포트만 원본에서 읽어 표시한다. 고배율은 nearest 표시로 원본 픽셀을 유지하며, 겹친 촬영을 평균해 결함이 겹쳐 보이는 현상을 피한다. 제공된 큰 합성본 위에 개별 원본 촬영을 우선한다. 실제 원본에 없는 세부 정보를 생성하지 않는다.

JPEG는 worker 소유 읽기 전용 디스크 캐시(최대 2개 / 합계 1.5 GiB 목표, 개별 2 GiB 안전 한도), 출력은 64 MiB LRU다. 개별 원본 하나가 1.5 GiB를 넘으면 해당 하나만 유지한다. 화면 패치는 최대 약 4 MP / 한 변 4096이다. 고해상도 화면이 이 예산을 초과하면 표시가 제한된다. TIFF는 기존 원본 영역 읽기 예산을 따른다. 정합 세대와 표시 revision을 분리하여 상세 화면이 갱신되어도 확대 배율을 초기화하지 않는다. 오래된 Pan 요청은 교체·무효화한다.

3D는 인접 페이지에 닿는 모든 성분을 합치던 동작을 제거한다. 클릭한 성분의 거리 기반 basin, 초기 결함 대비 성장 제한, 이전 페이지 접촉 근거로 하나의 제안을 선택한다. 경쟁 성분의 접촉 근거가 비슷하거나 면적·폭이 급격히 커지면 자동 합치기를 멈춘다. 빈 페이지를 건너뛰거나 마스크 밖 픽셀을 추가하지 않는다. 실제로 접촉한 두 물리적 결함을 영상만으로 항상 구분할 수는 없다.

## 사용

TIFF에서 결함 3D 도구로 검은 결함 안쪽을 클릭한다. 선택 페이지 → 뒤쪽 페이지 → 앞쪽 페이지 순서로 실제 인식 마스크와 쌓이는 층이 표시된다. 전체 사진의 위치 상자와 확대 inset, 결함 확대 화면을 제공한다. 마스크 강조 후 해당 층이 내려앉으며, 모호한 페이지는 노란색으로 표시하고 쌓지 않는다.

일시정지 / 다음 단계 / 빠르게 완료 / 과정 다시 보기를 사용할 수 있다. 다른 결함 제외는 현재 화면에서 제외 지점을 클릭하고 같은 seed로 다시 추적한다. 제외 지점은 이 세션의 표시용 제약이며 분석 입력·ROI·정답 라벨을 수정하지 않는다. 큰 합류를 수동 제약으로도 분리할 수 없으면 여기까지의 결과를 유지하거나 다시 선택한다.

Worker는 한 프레임의 승인 신호를 기다려 전체 페이지 화면이 메모리에 누적되지 않는다. 취소·파일 전환·종료는 대기를 해제한다. 다른 작업공간으로 이동하면 시각화 대기를 끝내고 계산을 마친다. 적층 재생은 저장된 실제 관찰 마스크와 다시 읽은 원본으로 실행하며 추론을 꾸며내지 않는다.

## 검증 및 한계

- RGB TIFF 원본 Crop과 100/200/400% 출력의 픽셀 일치, 90도 회전의 픽셀 중심, 겹친 촬영의 평균 방지
- JPEG 한 번 디코딩/동일 영역 LRU 재사용, 원본 변경 거부, 취소, 낮은 배율에서 불필요한 원본 디코딩 방지
- 단일 합성 결함 원본·마스크·폐곡면 보존, 붙은 blob 분리, 급격한 합류/모호한 분기 중단, 제외 marker, 실제 관찰 순서
- 시각화 일시정지의 backpressure, 빠르게 완료, 재생·취소와 기존 UI 회귀
- 실제 N119 158페이지 uint16 TIFF, seed (1667,1444,page_index=50): 이전 검증 115페이지/428157 voxels → 현재 22페이지/3452 voxels. page_index=57에서 AMBIGUOUS_MERGE, 34에서 NO_CONTACT. CPU 단회 추적 0.312초. 알고리즘/범위가 바뀌었으므로 속도 개선 비율로 해석하지 않는다.
- 실제 사용자 폴더 After annealing_2_x100: PROVIDED_COMPOSITE 16개 중 정합 16개, 원본 확대 표시 확인. 기존 손상 1.jpg는 읽지 못하며 원본은 보존한다.
- Windows Direct3D11 실제 마우스 선택·원본/마스크/적층·재생·웨이퍼 확대·Zoom 하한 유지·원본 SHA 검증 PASS, QML 경고 0 (초기 통합 검증).

실제 동일 결함 정답과 물리 Z 간격은 제공되지 않았다. 22페이지 결과를 물리적 단일 결함의 정답 또는 실제 깊이로 승인하지 않는다. XY는 원본 픽셀, Z는 페이지 인덱스다. 실험적 표시 분할은 ONNX 결과와 별개다. 원본·bit depth·ROI·분석 입력·Native Dialog·저장 형식은 보존한다.
