# Fluent 공통 UI 정리 (#143)

## 적용 범위

- 프로그램 0.5.0은 Qt Quick Controls의 공식 FluentWinUI3 스타일을 사용한다.
- UI/viewer extras의 PySide6 최소 요구 버전은 6.8이다. 검증·배포 런타임은 기존 6.11.2로 유지한다.
- `ui/style.py`를 실제 앱과 frozen smoke가 공유한다. 기존 다크 작업공간과 Fluent의 색상 모드를 일치시킨다.
- 버튼·텍스트 입력·체크박스·콤보는 공식 컨트롤 배경/표시를 사용한다. 기존 공통 컴포넌트 API와 액션 연결은 유지한다.
- 본문 14px, 일반 입력 36px, 기본 실행 40px, 도구 버튼 36px로 조정한다. 상단 메뉴 32px·도구 모음 52px·상태 표시 28px이며 내비게이션·기본 패널 폭은 유지한다.
- 선택·호버·키보드 포커스와 다크 팔레트를 통일한다. 내비게이션은 키보드로 사용할 수 있는 ItemDelegate로 바꾼다.
- 분석 확인창은 파일·범위·ROI/상세·실행 순서로 배치한다. 결과 화면은 총수·분류 필터·선택 카드·목록·내보내기를 구분한다.
- ROI 상세창의 외접 사각형 적용 버튼은 스크롤 영역 밖 하단에 고정한다. 원본 ROI를 분석 범위로 복사하는 계약은 유지한다.
- 대화상자 padding/inset을 통일하고 기본 implicitWidth를 지정해 크기 바인딩 순환을 방지한다.

## 보존

Viewer 렌더링·Pan/Zoom·좌표 변환·원본·ROI·분석 입력·모델·점수·내보내기·검수 저장·Native Dialog 구현을 변경하지 않는다. 전체 이미지와 단일 페이지 TIFF 분석, 여러 페이지 TIFF의 3D 흐름도 유지한다. 이 작업은 과학적 검출 성능 개선을 주장하지 않는다.

## 검증 방식

- 기존 분석·도구·캐시·결과·업데이트 회귀를 유지한다.
- 출하 스타일은 별도 Qt 프로세스로 100/125/150/200% DPI에서 1100×700, 1440×900, 1920×1080의 분석·결과·도구 배치를 검사한다. 100%에서는 팝업·포커스·대비도 검사한다.
- Fluent의 모달 전환 애니메이션이 끝난 뒤 다음 입력을 보내도록 테스트를 조정한다. offscreen 플랫폼은 QStyleHints 색상 모드를 제공하지 않을 수 있으므로 실제 Windows 렌더링을 별도로 확인한다.
- 합성 데이터 UI fixture와 실제 XRT 원본 열기 검사를 구분한다. 합성 화면은 모델 정확도 근거로 사용하지 않는다.
- 빌드 단계에서 모든 Fluent 자산의 존재를 확인한다. 실행 시 무결성 manifest에는 주요 QML·plugin을 포함하고, 실제 frozen 실행에서 새 스타일을 검증한다.
