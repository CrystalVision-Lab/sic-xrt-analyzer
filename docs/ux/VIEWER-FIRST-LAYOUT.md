# 넓은 기본 Viewer와 상단 분석 진입

Issue: [#90](https://github.com/CrystalVision-Lab/sic-xrt-analyzer/issues/90)

## 동작

- 시작, 파일 열기 완료, 데모 열기, 닫기, 화면 배치 초기화에서는 오른쪽 정보 패널을 접는다.
- 상단 오른쪽 **분석하기**는 기존 분석 준비 화면을 연다. 자동 추론하지 않으며 기존 모델·입력·범위 점검과 **분석 실행** 버튼을 유지한다.
- 상단 **패널 ▾**에서 이미지 정보, 뷰어·스택, ROI 관리, 분석, 결과, 검수를 연다. ROI 표시도 같은 메뉴에서 켜고 끈다.
- 패널 헤더 **×**로 닫고 Viewer에 포커스를 돌려준다. 메뉴로 다시 열어도 분석 결과와 ROI 기록은 유지한다.
- 분석 실행·완료·실패·취소, 후보 선택, ROI 가져오기·편집, 검수 요청은 해당 작업 패널을 자동으로 연다.
- 진행 상황, Pan/Zoom, 페이지 이동으로 사용자가 닫은 패널을 다시 열지 않는다.
- 파일명·해상도·타입·현재 페이지는 기존 Viewer Header와 상태 표시줄에서 계속 확인한다. 상세 메타데이터는 요청 시 표시한다.

## 화면 크기

기본 navigation 184px 유지 시 1100px 창의 Viewer 폭은 634→916px,
1440px 창은 974→1256px이다. 필요할 때 연 이미지/분석 패널 282px와
결과 380px, 검수 440px 정책은 그대로다. 이미지 종횡비와 Fit은 확장된
실제 viewport에 따라 계산한다. 이것은 화면 배치 변경이며 렌더링 지연이나
캐시 성능의 개선을 주장하지 않는다.

## 보존

원본 TIFF/JPG, bit depth, 원본 좌표 및 ROI geometry, 분석/ONNX/분류/결과,
ImageJ/Fiji, Export와 Native Dialog 구현을 변경하지 않았다. 기존 사용자
AGENTS.md 수정도 보존한다. 작업 환경은 D 프로젝트이며 실행 중인 프로그램은
재시작해야 변경된 UI를 사용한다.

## 검증

관련 UI 회귀, 1100×700/1440×900의 기본 전체 폭·우측 상단 버튼 접근성,
정보/분석/결과 패널 열기·닫기와 결과 보존, TIFF 페이지 이동 및 ROI 기록
보존을 QTest로 검사한다. 자동 입력이며 물리 마우스 Acceptance는 아니다.
최종 검사 수와 CI는 PR에 기록한다.


### 로컬 결과 (2026-10-12)

- 관련 UI 검사는 101개가 통과했다(기존 그룹 34개, 두 번째 그룹 63개와 수정된 4개 재검사). 신규 3개 검사를 포함한다.
- 최초 새 검사에서 모델 입력 형식/ROI 변경 확인/결과 레이아웃 반영 대기를 빠뜨린 fixture 오류와, 기존 long-filename 검사의 항상 열린 패널 가정이 실패했다. 기존 입력 제한 및 ROI 확인 로직은 유지하고 검사 준비를 수정했다. 최종 해당 4개 PASS, 8.20초 실행 명령 exit0.
- Ruff, compileall, 변경 파일 whitespace 검사 PASS. 사용자 AGENTS.md SHA256는 작업 전후 동일하다.
- Windows native Qt 합성 TIFF 화면 1100×700/1440×900 캡처 확인, QML 경고 0. 캡처는 ignored artifacts에 보관한다.
- 전체 Linux 회귀와 PR 정책 CI 결과는 연결 PR에서 확인한다. 이번 작업에서는 원본 XRT 성능이나 Native Dialog 안정성을 다시 판정하지 않는다.
