# 차분한 다크·민트 작업 공간 (#154)

## 사용자 흐름

분석 결과는 `전체 분포`로 열린다. 축소 화면의 숫자 원 대신 현재 필터에 맞는 후보 수를 영역별 밝기로 표시한다. 이 밝기는 위험도나 확률이 아니며, 빈 영역을 정상으로 판정하지 않는다. 영역 선택 또는 `영역 검토 시작`으로 원본 좌표의 해당 영역을 확대한다.

- **영역 검토:** 같은 영역의 후보를 하단 썸네일에서 선택한다. 후보마다 카메라를 반복 이동하지 않고 주변 후보를 함께 유지한다. 전체 지도에 현재 확대 범위와 선택 위치를 표시한다.
- **후보 비교:** 필터에 맞는 후보를 24개씩, 동일한 128 px 원본 범위의 패치로 비교한다. 썸네일은 화면 표시 크기로 축소된다. 원본 가장자리나 128 px보다 작은 이미지에서는 읽기 범위를 원본 안으로 제한한다. 후보 화살표는 필터 전체 순서를 따르고 선택 후보의 비교 페이지도 따라간다.
- **검출 숨김:** 연구 모델의 검출 표시를 숨긴다. ROI, 사용자 주석, 별도 구조·검수 레이어까지 제거한다는 의미는 아니다.
- **확인 / 보류:** 명시적으로 선택한 후보에만 검토 상태를 기록한다. 영역을 열거나 높은 모델 점수를 보았다는 이유로 확인 처리하지 않는다.
- **신고 대기:** 기존 신고 작성·로컬 대기열·전송 확인 절차를 사용한다. 비교 모드나 여러 후보 선택 자체로 서버에 전송하지 않는다.

BPD는 기존 `bpd_region` 윤곽 제안을 표시한다. TED/TSD와 클래스 색을 구분하고 선택 후보를 강조한다. 이번 변경은 모델 학습, BPD 분할 정확도, 3D 연결 추적 알고리즘을 바꾸지 않는다. 3D 교차 연결이 모호할 때는 원본 확인과 같은 결함 지정으로 이어가는 안내를 보강한다.

## 공통 표현

`Theme.qml`의 어두운 배경·민트 포인트·모서리 반경과 `AppButton.qml`의 기본/주요/선택/포커스 상태를 공유한다. 공통 버튼과 대화상자를 쓰는 TIFF, Wafer Map, 정합, 프로젝트, 신고, 업데이트 화면에도 적용된다. TIFF 준비 화면은 현재 페이지에서 가능한 행동을 안내하고 업데이트 화면은 주 행동과 보조 설정을 분리한다. 각각의 복잡한 작업 화면을 동일한 레이아웃으로 교체한 것은 아니다.

## 구성과 제한

- `UiState.resultViewMode`와 `RegionReview.presentation`이 화면 모드를 연결한다. 새 분석 ID에서는 전체 분포로 돌아간다.
- `ResultDensityOverlay.qml`은 원본 좌표 영역을 뷰 변환으로 그린다. 클릭과 패널 버튼 모두 동일한 `selectArea`를 사용한다.
- `ResultCandidateShelf.qml`은 가상화된 GridView로 후보를 표시한다. `ResultExplorer.qml`은 요약, 필터, 선택 상세와 결정 버튼을 담당한다.
- 비교 패치는 백그라운드에서 24개씩 읽는다. 서로 멀리 떨어진 후보를 감싸는 거대한 사각형을 한 번에 읽지 않는다. 비동기 결과는 최신 요청만 반영한다.
- 영역 썸네일은 최대 512개를 준비하며, 초과 후보는 삭제하지 않고 `선택하여 원본 보기`로 표시한다. 비교 화면에서 페이지별로 모든 필터 후보를 볼 수 있다. 읽기 실패는 준비 중 상태와 구분한다.
- 열어본 영역과 직접 확인한 후보 수는 별도 표시한다. 원본/분석 결과 내보내기와 검토 기록은 별도로 유지한다.
- 최소 검증 창은 1100×700이다. 좁은 패널에서 레이아웃의 암묵적인 최소 너비로 내보내기가 잘리지 않도록 축소 제약을 명시했다.

## 호환성

서버 API, 신고 페이로드, 모델 계약·해시, 분석 결과 스키마, 프로젝트 저장 스키마, 업데이트 서명 검증은 변경하지 않는다. 추가된 `RegionReview.state` 필드는 로컬 QML 표시용이다. 런타임 의존성은 추가하지 않는다. 원본 픽셀과 검출 좌표/점수는 UI 전환이나 검토 상태 저장으로 수정되지 않는다.

## 검증 방법

`tests/test_soft_workspace.py`는 분포 수 일치, 영역 이동, 같은 영역의 카메라 유지, 명시적 검토, 비교 페이지 이동/선택 유지, 전송 없음, 내보내기 내용 보존을 검증한다. 기존 결과 탐색·작은 창 배치 검사는 하단 후보 선반을 대상으로 갱신했다.

`tools/validate_soft_workspace.py --output <새 디렉터리>`는 합성 이미지와 고정된 합성 검출을 사용해 실제 QML의 1440×900/1100×700 화면과 업데이트 대화상자를 저장하고 QML 경고를 확인한다. 무인 검증에서는 `QT_QPA_PLATFORM=offscreen`, `QSG_RENDER_LOOP=basic`을 지정한다. 이 화면은 모델 성능 또는 실제 시료 분석의 증거가 아니다. 생성 이미지와 캡처는 Git에 넣지 않는다.
