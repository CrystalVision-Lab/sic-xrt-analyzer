# sic-xrt-analyzer

SiC XRT 이미지의 데스크톱 분석 앱입니다. PySide6/QML UI, TIFF 로딩, 웨이퍼 맵, 이미지 정합, 3D 시각화, 승인된 ONNX 모델 추론을 이 저장소에서 다룹니다. 기능 구현은 각 GitHub Issue에서 범위를 먼저 정합니다.

## 시작

- Python 3.11 이상
- 개발 도구: `python -m pip install -e ".[dev]"`
- UI 실행: `python -m pip install -e ".[ui]"` 후 `python -m sic_xrt_analyzer`
- 검사: `ruff check .`, `pytest` (`pytest`의 UI 스모크 검사는 PySide6가 필요합니다)

## TIFF 뷰어

`python -m sic_xrt_analyzer`로 1440×900 기본 창을 엽니다. 창은 1100×700까지 줄일 수 있고 좌우 패널을 접어 이미지 영역을 넓힐 수 있습니다. 상단 **이미지 열기** 또는 `Ctrl+O`로 TIFF 파일 선택 창을 열 수 있습니다. 취소하면 현재 파일 선택은 유지됩니다.

창 상단의 메뉴에서 **파일**(TIFF 열기·데모·종료), **편집**(이동·관심 영역), **보기**(배율·패널), **작업 영역**, **설정**(오른쪽 패널의 이미지·분석·결과 탭), **분석**, **도움말**을 사용할 수 있습니다. 모델 분석 실행은 아직 비활성화되어 있습니다.

- **이미지 분석**: TIFF 파일을 선택하면 첫 번째 페이지를 읽어 뷰어에 표시합니다. 8/16비트 등 숫자형 회색조와 RGB/RGBA 이미지를 지원합니다. 화면에는 8비트 미리보기를 표시하며, 큰 이미지는 긴 변 4096픽셀 이하로 축소합니다. 확대·축소, 화면 맞춤, 이동, 관심 영역 표시가 동작합니다. 파일 열기에 실패하면 오류를 표시하고 이전 이미지를 유지합니다.
- **데모 보기**: 실제 SiC 데이터가 아닌 합성 샘플을 엽니다. 상단 확대·축소, `화면 맞춤`, 마우스 휠, 뷰어의 이동·영역 선택을 시험할 수 있습니다. 배율 100%는 화면 맞춤을 기준으로 합니다. `Ctrl+0`, `Ctrl++`, `Ctrl+-`도 사용할 수 있습니다.
- **Wafer Map·이미지 정합·3D 보기**: 탐색 항목과 준비 안내 화면만 제공합니다.
- **정보 및 설정**: 파일명, 원본 이미지 크기, 픽셀 비트 깊이, 페이지 수를 표시합니다. 물리 스케일은 아직 읽지 않으며 밝기·대비·결함 레이어는 비활성화되어 있습니다. 모델은 미연결이며 분석 실행도 비활성화되어 있습니다. 결과 화면은 분석 전 빈 상태를 보여줍니다.

UI는 `src/sic_xrt_analyzer/ui/`의 QML 컴포넌트와 공통 상태 객체로 구성됩니다. TIFF 로더는 `tifffile`로 첫 페이지를 읽고 Qt 이미지 제공자를 통해 미리보기를 전달합니다. `imagecodecs`는 압축 TIFF 디코딩에 사용합니다. 16비트와 부동소수점 값은 표시 목적으로 1~99 백분위 범위를 8비트로 변환합니다. 원본 픽셀 데이터는 분석 파이프라인에 전달되지 않으며, 다중 페이지 탐색·물리 스케일·원본 좌표 기반 분석은 아직 구현하지 않았습니다. 결함 라벨과 분석 성능은 아직 정하지 않았습니다.
